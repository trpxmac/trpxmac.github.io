3. iPad Document e-Sign Pipeline

ระบบลงนามเอกสารดิจิทัลบน iPad เชื่อมโยงระบบโรงพยาบาล iMed (HIS) และ EDSCare (EHR)

  • • สถาปัตยกรรม Pure PDF Vector Pipeline คมชัดระดับเวชระเบียน ขนาดไฟล์เล็ก (~14–300 KB)
  • • บริการสกัดข้อความดิจิทัล 100% จากใบประเมินราคาด้วย Python (PyMuPDF) คำนวณเงินมัดจำ 80% อัตโนมัติ
  • • รองรับการเขียนหมายเหตุและลงนาม 3 ช่องด้วย Apple Pencil พร้อมฝัง Audit Trail และระบบแจ้งเตือนเอกสารตกค้าง
